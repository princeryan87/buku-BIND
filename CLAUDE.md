# Aturan proyek
- Komputer ini TIDAK punya Flutter atau Android SDK. Jangan menjalankan flutter build, flutter run, flutter pub get, atau gradlew.
- Hanya edit kode. Build dijalankan oleh GitHub Actions setelah saya push.
- Jangan ubah file di .github/workflows atau pengaturan signing tanpa izin saya.
- Jangan membaca atau menampilkan file .env, keystore, atau key.properties.
- Jangan commit atau push sendiri. Saya yang melakukannya, dengan kamu memberikan opsi YES or NO.
- Bekerja di branch fcc-eksperimen, jangan pindah ke main.
